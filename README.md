# ATHEUS

Premium creative web studio portfolio for `atheus.dev`.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Deployment-ready static routes

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```
