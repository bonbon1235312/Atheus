# Lowry's concept — content and asset notes

This route is a client preview, not an official business website. It has noindex/nofollow metadata and is intentionally absent from the marketing sitemap and navigation.

Owner sign-off is still needed for: current menu/prices, hours, business story, bakery range, dietary/allergen wording, dog policy, access, parking, and any review snippets. The preview contains no food prices, hours, review scores, booking form, or ordering system. No message has been sent to the prospect.
